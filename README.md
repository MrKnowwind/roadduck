# 街头小勇士

一个使用 Phaser 4 和 Vite 开发的俯视角过马路 H5 小游戏。控制小鸭避开车流、穿过道路并抵达顶部终点。每次成功过街都会解锁新的玩法机制，难度逐步提升。

## 游戏特色

- 棋盘式四方向移动
- 多车道双向车流
- 车辆安全车距与冲刺规则
- 键盘、触屏滑动和屏幕按钮操作
- 手机与桌面浏览器自适应
- 本地保存最高过街次数
- 过关机制说明卡

## 递进机制

每次成功抵达终点都会保留已有机制，并加入下一项挑战：

1. **车流提速**：所有车辆提高行驶速度。
2. **冲刺快车**：闪电车辆会在安全车距足够时短暂冲刺。
3. **夜幕降临**：仅保留角色周围的圆形视野，车灯提示车辆位置。
4. **施工路障**：草地出现不可通行的施工围栏。
5. **逆向车道**：部分车道改变行驶方向。
6. **全城警报**：所有车辆间歇性爆发加速。
7. **极限叠加**：继续保留全部机制并逐轮提高车速。

## 操作方式

| 设备 | 操作 |
| --- | --- |
| 电脑 | 方向键或 WASD |
| 手机 | 滑动游戏画面或点击右下角方向按钮 |
| 重新开始 | 撞车后点击画面或按任意方向键 |

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm 10 或更高版本

## 安装与运行

```bash
npm install
npm run dev
```

启动后打开终端中显示的本地地址，默认通常为 `http://localhost:5173/`。

## 测试与构建

运行规则测试：

```bash
npm test
```

生成生产版本：

```bash
npm run build
```

构建结果会生成在 `dist/` 目录中。
