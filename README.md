# 街头小勇士

一个使用 Phaser 4 和 Vite 开发的俯视角过马路 H5 小游戏。控制小鸭避开车流、穿过道路并抵达顶部终点。每次成功过街都会解锁新的玩法机制，难度逐步提升。

## 游戏特色

- 棋盘式四方向移动
- 多车道双向车流
- 每条车道按波次随机生成 1～4 辆车，并随机变化车距与波次空档
- 车头碰撞会失败，碰到车身侧面会触发受惊退格动画
- 键盘长按与触屏持续滑动操作
- 手机与桌面浏览器自适应
- 本地保存最高过街次数
- 过关机制说明卡

## 递进机制

前 7 关每关只启用一个主要机制，不会继承上一关的机制；第 8 关起随机组合多项机制，关卡越高，同时出现的机制越多：

1. **车流提速**：所有车辆提高行驶速度。
2. **冲刺快车**：闪电车辆会在安全车距足够时短暂冲刺。
3. **夜幕降临**：仅保留角色周围的圆形视野，车灯提示车辆位置。
4. **施工路障**：草地出现不可通行的施工围栏。
5. **逆向车道**：部分车道改变行驶方向。
6. **全城警报**：所有车辆间歇性爆发加速。
7. **复合挑战**：第 8 关起随机组合 2 项机制，之后逐步增加，最多同时出现全部 6 项。

随着关卡推进，道路会重新生成：连续车道由双车道逐渐增加到 3、4、5 车道，道路总行数也会提升。

## 操作方式

| 设备 | 操作 |
| --- | --- |
| 电脑 | 点击或长按方向键、WASD；长按会持续移动 |
| 手机 | 按住并朝一个方向滑动会持续移动；不松手改向时立即切换方向 |
| 重新开始 | 撞车后点击画面或按任意方向键 |

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm 10 或更高版本

## 安装与运行

```bash
npm install
npm run dev
```

启动后打开终端中显示的本地地址，默认通常为 `http://localhost:5173/`。

## 测试与构建

运行规则测试：

```bash
npm test
```

生成生产版本：

```bash
npm run build
```

构建结果会生成在 `dist/` 目录中。
